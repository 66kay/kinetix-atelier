# KINETIX ATELIER // High-End Performance & Technical Footwear

Tienda online y catálogo editorial de calzado técnico, running y streetwear de alto rendimiento adaptada al mercado chileno (CLP).

![Vista Previa](https://images.unsplash.com/photo-1542291026-7eec264c27ff?w=1200&auto=format&fit=crop&q=85)

## ✨ Características Principales

- **Diseño Editorial & UI de Alto Nivel:** Estética contemporánea inspirada en marcas de lujo técnico (Salomon Advanced, On Running, Kith).
- **Moneda Nacional Chilena ($ CLP):** Precios, subtotales, cupones y cálculos adaptados con separador de miles.
- **Efecto Dual-Photo en Hover:** Muestra automáticamente una segunda perspectiva y detalle de la misma zapatilla al pasar el ratón por cada tarjeta.
- **Bolsa de Compra Deslizante (Slide-Over Drawer):** Control de cantidades, cálculo de totales, barra dinámica de meta para envío gratuito a todo Chile ($90.000 CLP) y cupones de descuento válidos (`BIENVENIDA10`, `CHILE15`).
- **Modal de Vista Rápida (Quick View):** Galería con miniaturas interactivas, selección de tallas (EU 38-45) y ficha técnica de composición.
- **Checkout Adaptado a Chile:** Selección de regiones chilenas, comunas y medios de pago locales (Webpay Plus Transbank, Mercado Pago, MACH).
- **Filtros Dinámicos y Búsqueda en Vivo:** Filtrado por categoría (*Running, Trail & Outdoor, Lifestyle, High-Top*) y buscador en tiempo real.
- **Sección Editorial / Lookbook:** Fotografía y estilo de vida en entornos reales (ciudad y montaña).
- **100% Responsive:** Experiencia optimizada para móviles, tablets y pantallas de escritorio.

---

## 🛠️ Tecnologías Empleadas

- **HTML5 Semántico:** Estructura limpia y accesible.
- **CSS3 Moderno:** Variables CSS, Flexbox, CSS Grid, desenfoque de fondo (*backdrop-filter*) y animaciones fluidas.
- **JavaScript ES6 (Vanilla):** Sin librerías pesadas ni dependencias externas, reactividad nativa y persistencia en `localStorage`.

## 🚀 Puesta en Marcha Local

Para visualizar el proyecto localmente:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/66kay/kinetix-atelier.git
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd kinetix-atelier
   ```
3. Abre directamente el archivo `index.html` en tu navegador, o inicia un servidor local simple:
   ```bash
   python -m http.server 8080
   ```
   E ingresa a [http://localhost:8080](http://localhost:8080).
